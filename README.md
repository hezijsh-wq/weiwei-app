# 星间 · STAR MEMORY

面向金希澈、韩庚、金在中粉丝的移动端优先 Web APP 原型。包含资讯、时光馆、活动日历、社区、收藏，以及「那年今天，我们在看什么」回忆留言。

## 运行

需要 Node.js 22 或更新版本，无第三方运行依赖。

```sh
npm start
```

默认端口为 3000，可通过 `PORT` 覆盖。运行 `npm run check` 检查 JavaScript 语法。

## 原型边界

- 所有资讯、时间线和活动均明确标为示例，不代表艺人真实消息或行程。
- 收藏、社区发帖、点赞、留言与活动清单使用当前浏览器的 localStorage；尚无账号、后端、跨设备同步和在线社区。
- 加入活动清单不会触发系统通知。
- 图片为本地原创 SVG 舞台与音乐氛围插画，并非艺人照片；使用系统字体，无外部资源请求。
- 正式上线前需接入可核验的内容来源、授权素材、账号服务和社区举报审核功能。
